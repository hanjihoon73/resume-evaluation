- **User Flow**
    - 앱 실행 및 로그인
        1. 웹사이트 접속
        2. ID/PW 입력 후 로그인
        3. ID, PW 찾기
    - 회사 정보 입력 및 채용 정보 세팅
        1. 회사 기본 정보 입력 또는 사업자등록증 사본 업로드
            1. 회사명
            2. 등록번호
            3. 사업자 종류: 개인 / 법인
            4. 창업일: 예) 2016년 7월
            5. 사업장: 예) 서울시 강남구 선릉로108길 51, 2층
            6. 업태:
        2. 회사에서 요구하는 태도 및 문화 입력
            1. 공통 문항 개발 필요
        3. 회사에서 요구하는 포지션 추가 및 채용 조건 입력 (md, pdf)
            1. 포지션 선택
            2. 포지션 추가
            3. 포지션에 채용 조건 입력 또는 파일 업로드 (md, pdf만 가능)
    - 이력서 분석
        1. 채용을 진행 중인 포지션 선택
        2. 지원자 이력서 업로드 (md, pdf) → 1명 당 파일 1개, 2개 이상의 지원자 업로드 가능
        3. 분석 요청
    - 리포트 확인
        1. 지원자별 분석 결과 표시 (목록 형태)
        2. 지원자별 리포트 확인 기능
        3. 지원자별 리포트의 복사 및 다운로드 기능 (md, pdf)
- **Database**
    - 사용자 로그인 세션 관리
    - 회사 정보 저장 관리
    - 채용 정보 저장 관리
    - 분석 결과 및 리포트 저장 관리
- **Critical Workflow**
    - 분석 요청 트리거
    - 회사 정보와 채용 정보 불러오기
    - 이력서의 주요 정보 추출하기 (AI prompt)
    - 추출된 정보를 회사 정보와 채용 정보 기준으로 분석하기 (AI prompt)
    - 분석 결과를 데이터로 저장하기
    - 저장된 데이터를 화면에 목록으로 출력하기
    - 개별 목록을 리포트 화면으로 출력하기
