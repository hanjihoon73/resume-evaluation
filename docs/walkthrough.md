# UI 디자인 고도화 및 데이터 정제 결과

사용자님의 요청에 따라 전반적인 UI의 완성도를 높이고 리포트 데이터의 정확성을 개선했습니다.

## 주요 변경 사항

### 1. 버튼 디자인 통일 (프리미엄 스타일 적용)
- **[새로 분석하기]**, **[목록으로]** 버튼에 **[PDF 다운로드]** 버튼과 동일한 프리미엄 그라디언트 스타일과 직관적인 아이콘을 적용했습니다.
- 통일된 디자인을 통해 더욱 세련된 사용자 경험을 제공합니다.

### 2. 데이터 표시 규칙 개선
- 이력서 본문에서 인적 사항을 차지 못할 경우, 기존 "N/A" 또는 "미기재" 대신 훨씬 깔끔한 **"-" (대시)** 기호를 표시하도록 변경했습니다.
- 적용 범위: 지원자 기본 정보(연락처, 이메일, 전공, 학점 등) 및 리포트 테이블 전체.

### 3. 학력 정보 정규화 (LLM 추론 고도화)
- 최종 학력을 **'학사'**, **'석사'**, **'박사'** 중 하나로 자동 분류하도록 AI 엔진 프롬프트를 고도화했습니다.
- 정보가 없는 경우에는 명확하게 **"-"**로 표시되어 데이터의 일관성을 유지합니다.

## 수정 결과 확인 방법
1.  이력서 분석 완료 후 **분석 결과 목록**에서 [새로 분석하기] 버튼 스타일 확인.
2.  개별 **리포트 화면**에서 [목록으로] 버튼 및 정보 부재 시의 '-' 표시 확인.
3.  **PDF 리포트** 생성 시 정보들이 깔끔하게 정돈되어 출력되는지 확인.
